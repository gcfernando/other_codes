### 🪟 System Maintenance

Review [`SystemMaintenance/SystemMaintenance.ps1`](SystemMaintenance/SystemMaintenance.ps1) before running. From an **elevated PowerShell** window at the repository root:

```powershell
.\SystemMaintenance\SystemMaintenance.ps1
```

> ⚠️ **This script makes system-wide changes.** It may install Windows updates, repair the system image, schedule disk repairs, reset network settings and adapters, remove temporary files and crash dumps, and stop and restart a Windows service. Back up important data, save your work, and understand the script before execution. Run it only on a machine you administer.

### 🔁 Line Ending Converter

Converts a single file or an entire folder (skipping `.git`, `bin`, `obj`, and `node_modules`). The second argument is the **current** line ending to convert **from**:

```powershell
# 🔄 LF  ➜ CRLF
.\Files\Convert-LineEndings.ps1 "C:\Projects\MyRepo" LF

# 🔄 CRLF ➜ LF
.\Files\Convert-LineEndings.ps1 "C:\Projects\MyRepo" CRLF

# ✅ Verify the result in a Git repository
git ls-files --eol
```

> 🛡️ Files are rewritten as UTF-8 without BOM. Empty files, binary files, files that already have a UTF-8 BOM, and files that are not valid UTF-8 are skipped rather than modified. Commit or back up your work before converting a whole folder.

### 🐧 WSL2 Config

Copy [`Files/.wslconfig`](Files/.wslconfig) to your Windows user profile folder (`%UserProfile%\.wslconfig`), adjust the values for your machine, then restart WSL:

```powershell
wsl --shutdown
```

| ⚙️ Setting | Value |
| --- | --- |
| 🧠 `memory` | `8GB` |
| 🖥️ `processors` | `8` |
| 💾 `swap` | `4GB` |
| 🔌 `localhostForwarding` | `true` |
| 🔥 `firewall` | `true` |
| 🌐 `dnsTunneling` | `true` |
| 🧭 `autoProxy` | `true` |
| ♻️ `autoMemoryReclaim` *(experimental)* | `dropCache` |

### 🧰 Local Services Stack

Requires Podman with Compose support. From the repository root:

```powershell
podman compose -f Files/compose.yml up -d
podman compose -f Files/compose.yml ps
```

⏹️ To stop the services while keeping their data:

```powershell
podman compose -f Files/compose.yml down
```

🗑️ To also remove the stack's persistent data volumes:

```powershell
podman compose -f Files/compose.yml down -v
```

> 🔐 **Local development only.** The compose file contains default credentials and disables Elasticsearch security. Change the credentials before starting the stack, and do not expose these services to untrusted networks or use the configuration in production.

## ❓ FAQ

**How do I install a Claude Code plugin, MCP server, or Copilot CLI add-on as a beginner?**
Open the [AI coding add-ons beginner's guide](https://gcfernando.github.io/other_codes/Files/ai_coding_plugins_beginners_guide.html). Every add-on has separate install, configure, and use-in-your-project steps for each supported tool, plus "how to know it worked" checks.

**Is there a Linux command cheat sheet that works offline?**
Yes — open [`Linux_Commands/index.html`](Linux_Commands/index.html) directly in a browser. It needs no server or build step and lets you search and filter the commands by category.

**How do I run SQL Server, MongoDB, and other databases locally with Podman?**
Use the [Local Services Stack](#-local-services-stack): `podman compose -f Files/compose.yml up -d` starts all services with persistent volumes. It is for local development only.

**How do I convert line endings between LF and CRLF on Windows?**
Run [`Files/Convert-LineEndings.ps1`](Files/Convert-LineEndings.ps1) on a file or folder, then check the result with `git ls-files --eol` (see [Line Ending Converter](#-line-ending-converter)).
